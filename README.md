## 💌 Fitur Undangan

- **Cover overlay** — nama tamu diambil dari query params `?name=...`
- **Countdown** — hitung mundur menuju hari H
- **Animasi reveal on scroll** — efek muncul bertahap saat scroll
- **Dekorasi bunga** (SVG) — ornamen floral di setiap section
- **Floating petals** — animasi kelopak bunga di latar
- **Navigasi floating** — navigasi cepat (desktop & mobile)
- **Music toggle + volume slider** — kontrol musik latar

## 🛠️ Tech Stack

| Teknologi           | Keterangan                 |
| ------------------- | -------------------------- |
| **Vue 3**           | Framework utama            |
| **TypeScript**      | Bahasa pemrograman         |
| **Vite**            | Build tool & dev server    |
| **Vue Router**      | Routing SPA                |
| **Tailwind CSS v4** | Utility CSS framework      |
| **ESLint + Oxlint** | Linting & static analysis  |
| **Prettier**        | Formatter                  |
| **vue-tsc**         | Type-checking `.vue` files |

---

## 🚀 Cara Menjalankan

```sh
# Install dependencies
npm install

# Development (hot-reload)
npm run dev

# Type-check
npm run type-check

# Build production
npm run build

# Preview production build
npm run preview

# Lint & format
npm run lint
npm run format
```
